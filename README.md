# secureaiarch.com

Reference architectures for on-prem LLM, RAG and agent systems, tested on local hardware. The site is published in English and Turkish.

## Layout

| Path | Purpose |
|---|---|
| `bench/` | Test harness. Runs against Ollama, standard library only. |
| `bench/data/` | Hand-labelled synthetic inputs. |
| `results/<pattern>.json` | Summary shown on the site. Not written by hand; generated by `bench`. |
| `results/raw/<pattern>/<model>.jsonl` | Every request and reply. |
| `src/content/patterns/<slug>/{en,tr}.md` | Pattern text. |
| `src/diagrams/` | Topology diagrams (SVG, follow the site theme). |

A pattern without a results file is shown on the site as a draft, gets `noindex` and is left out of the sitemap.

## Generating results (Mac Mini)

```sh
for m in qwen2.5:1.5b qwen3.5:4b qwen3:8b qwen3.6:35b-a3b-q8_0; do ollama pull "$m"; done
BENCH_MACHINE="Mac mini M4 Pro 64GB" python3 -m bench run structured-output \
  --models qwen2.5:1.5b,qwen3.5:4b,qwen3:8b,qwen3.6:35b-a3b-q8_0
git add results && git commit -m "structured-output results" && git push
```

The push triggers the deploy. The machine running the harness only makes outbound connections; nothing needs to reach it from the internet.
